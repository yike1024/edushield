AiSOC 大脑 · 核心技术亮点（汇报/文档可用）

====================================================
一、真正有独创性、比一般智能体有过人之处的点
====================================================

1. 领域先验以"规则轨 + RAG 软知识"双通道注入判定 —— 校园威胁模型双路独立
   - 规则轨（verdict/__init__.py）硬编码教育行业专属误报先验：
     搜索引擎爬虫 ≠ 攻击、选课高峰高并发 ≠ DDoS、图书馆/宿舍时段/教务登录 ≠ 异常、
     仅端口扫描做风险降级；
   - RAG seed 知识库另有一条"校园网常见误报场景"知识
     （宿舍批量刷课 ≠ DDoS、图书馆开馆密集搜索 ≠ 目录扫描、教师远程办公 ≠ 异常登录）；
   - 两条通道各自独立：即使 LLM 轨不可用，规则轨仍能给出可解释的 false_positive
     判定（rules_fired 记录每条命中规则名+描述，可复核）。
   - 意义：把"这所学校安全运营的真实业务逻辑"写进系统，而非通用 agent 包装。

2. 明确的"大脑/执行体"分界 + 结构化 Finding 作为多智能体协作货币（ADR-4）
   - orchestrator 写明：大脑不重写 agent 循环，重试/压缩/子代理/沙箱留在 reasonix 部件；
   - 智能体间传递物不是对话文本，而是 schema 化 Finding
     （cve/cwe/cvss/mitre/confidence/evidence/remediation），可落库、可审计、可被下游结构化消费。

3. 显式的跨智能体防注入设计
   - protocol.to_input_text() 规定：严禁把整包 JSON 当提示词原文丢给模型；
   - A 部件结果传给 B 时只传前 3 条 findings 摘要（≤500 字符），引用用 ref_task_ids 而非原文。

4. 针对"外部执行体不可靠"的现实韧性设计
   - 部件协议：先订阅 SSE 再 submit、等 turn_done、超时走 /status 兜底、断线重连 3 次；
   - 单会话串行锁防并发覆盖；
   - 会话隔离缓存 (session_id, domain) + /new + 6h TTL 滑动 + 30min GC；
   - 面向"队友 reasonix 实例会崩/会慢/会被重启"的真实多租户环境，非玩具 demo。

5. 可观察性内建
   - eventhub SSE 全链路事件：stage_start / findings_stored / verdict / report_ready；
   - pass_through 原样透传 reasonix 帧（10号契约）；
   - SQLite 落库：tasks/findings/ledger/stages/reports + /export 审计导出。

====================================================
二、有特色但不算独创的工程点
====================================================

- 双轨任务意图解析：规则兜底 + LLM 增强（parse_task_intent）；
- data_leak 管道 evidence 接力：logaudit 证据摘要定向喂 pentest
  （方向正确，但实现较薄：固定两段、摘要仅 3 条 500 字）；
- RAG 本地 embedding 离线可用（工程取舍，非能力亮点）；
- 目标授权白名单开关（安全加分，通用做法）。

====================================================
三、注意：看起来是卖点、实际尚未实现的点（对外别吹）
====================================================

- models/state.py 的 Planner/Worker/Analyst + LangGraph AgentState：全项目零引用，
  未使用 LangGraph 规划 —— 勿对外宣称；
- autoPlan / maxSubagentDepth / subagentEffort：runtime 有壳，行为未实现
  （设计文档见 docs/autoplan-design.md，待执行）；
- DeepSeek / 部件内 reasonix：属执行引擎，非本项目独创。

====================================================
四、一句话版本（对外口头用）
====================================================

AiSOC 的过人之处不在"又一个套 LLM 的 agent"，而在三层：
把校园安全运营的领域先验以规则+知识双路注入判定；
用结构化 Finding 协议在多智能体间传递可审计证据而非对话文本；
针对不可靠外部执行体设计的会话隔离与事件驱动韧性。
它更像一个面向校园安全运营的可插拔调度系统，而不只是会调大模型的机器人。
